# alma-normalization-rules
This repository contains Alma normalization rules developed by the University of Nebraska–Lincoln Libraries as part of a pilot project exploring the use of local authority records and normalization rules to implement reparative descriptive practices in library metadata.

The project aims to improve the language used in bibliographic records by identifying and replacing potentially harmful, outdated, or exclusionary subject terminology with more respectful and inclusive alternatives.

By sharing these normalization rules, we hope to support other libraries interested in implementing reparative metadata practices within Ex Libris Alma and encourage collaboration around sustainable approaches to vocabulary remediation.

The normalization rules in this repository were developed for use in Ex Libris Alma. Libraries interested in adopting them should review and adapt the rules to their local cataloging policies, authority control practices, and discovery environments.

This repository is the result of a completed pilot project, but the work has become a sustainable workflow at UNL Libraries. Rules and accompanying documentation may be added or revised as additional vocabulary changes are explored.

For questions about the project or the normalization rules, please contact: unl.metadata@unl.edu​
